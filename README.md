## Featured Projects

**[Text-to-SQL Clarification Engine](https://github.com/hamnaasiif/text-to-sql-clarification-engine)**
An AI system that detects ambiguous natural-language questions and asks a clarifying question before generating SQL, instead of guessing. Full pipeline (schema introspection, LLM-based ambiguity detection, SQL generation, safety validation), a React chat frontend, an automated test suite, and a live deployment — all on free-tier infrastructure.
Live demo: https://textsql-frontend-kappa.vercel.app

**[Signity]**
A multi-stage AI pipeline converting spoken Urdu/English into Pakistani Sign Language — speech recognition (Whisper), LLM-based gloss refinement, NLP-based sentence reordering, and a React frontend. Final-year project.

**[RPS Gesture Game](https://github.com/hamnaasiif/rps-gesture-game)**
Real-time hand gesture recognition running in-browser at 60fps, using React, MediaPipe, and TensorFlow.js.
Live demo: https://hamnaasiif.github.io/rps-gesture-game

**[Diffusion DDPM Project](https://github.com/hamnaasiif/diffusion-ddpm-project)**
A Denoising Diffusion Probabilistic Model built from scratch in PyTorch, with a custom U-Net architecture and cosine noise schedule, for synthetic image generation.

**[VLM-QLoRA Document-to-Markdown](https://github.com/hamnaasiif/VLM-QLoRA-Document2Markdown)**
Fine-tuned Qwen2-VL-2B-Instruct using QLoRA to convert document images into structured Markdown, built with PyTorch, Hugging Face, and Gradio.

**Portfolio Website**
